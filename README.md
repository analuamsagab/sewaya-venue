# Sewaya Venue Program

## Tech Stack
- PHP
- MySQL
- JSON
- AJAX

## Deployment

Winows :
- Install Xampp
- Run Apache
- Letakkan Source Code di dalam folder htdocs

Linux :
Clone Repository Ini 
```
git clone https://github.com/analuamsagab/sewaya-venue
```

Deploy
```
rm /var/www/html/index.html
mv sewaya-venue /var/www/html
```
